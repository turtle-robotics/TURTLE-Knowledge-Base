# Code of Conduct

TURTLE Robotics members must follow the rules in the [TURTLE Constitution](https://www.turtlerobotics.org/pdfs/TURTLE_Constitution.pdf).

## Conduct in This Repository

Be professional and respectful when you use this repository.

Follow these rules:

- Treat other people with respect.
- Give clear and useful feedback.
- Keep discussions related to the project.
- Do not use abusive, offensive, or harmful language.
- Do not harass or threaten another person.
- Do not publish private information without permission.
- Do not intentionally disrupt Issues, Pull Requests, Discussions, or reviews.

These rules apply to all activity in this repository.

## Report a Conduct Problem

Report conduct problems to TURTLE Senior Leadership as specified in Article 7 of the [TURTLE Constitution](https://www.turtlerobotics.org/pdfs/TURTLE_Constitution.pdf).

Do not report a sensitive conduct problem in a public Issue or Discussion.

## Enforcement

TURTLE Senior Leadership handles conduct problems according to the TURTLE Constitution.

Repository maintainers can moderate repository content when necessary. They can close discussions, remove content, or limit repository access.

If this document conflicts with the TURTLE Constitution, follow the Constitution.
